# 🚀 Onboarding Portal

A web-based onboarding system built using Django that allows candidates to securely log in, complete onboarding forms, and manage their profile.

---

## 📌 Features

- 🔐 User Login System
- 🔑 Change Password Functionality
- 📝 Dynamic Onboarding Form
- 🧾 Candidate Data Management
- 🧑‍💼 Admin Panel (Django Admin)
- 🎨 Clean UI with Navbar & Sidebar
- 🔒 Session-based Authentication

---

## 🛠 Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Deployment:** Render
